
# ✈️ Travel Packing Assistant

A beginner-friendly Python project that helps travellers prepare a packing checklist based on their destination and trip duration.

## 📌 About the Project

Packing for a trip can be confusing, especially when deciding what essentials to carry. The Travel Packing Assistant makes this easier by generating a simple checklist for travellers.

This project is being developed as part of my Python programming learning journey.

## ✨ Features

- Enter your travel destination.
- Specify the duration of your trip.
- Generate a basic packing checklist.
- Display essential travel items.
- Simple and beginner-friendly interface through the terminal.

## 🛠️ Technologies Used

- Python 3

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   `python travel_packing_assistant.py`

5. Enter your destination and trip duration when prompted.

## 📂 Project Structure

- `travel_packing_assistant.py` — Main Python program.
- `README.md` — Project documentation.
